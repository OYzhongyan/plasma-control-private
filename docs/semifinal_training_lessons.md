# 复赛训练经验与设计原则

本文档记录当前团队对复赛任务、训练课程、reward、观测归一化和 shot/目标匹配的共识。它不是官方说明的替代，而是用于指导后续代码实现和实验排期的工程约束。

## 1. 任务与 shot 语义

复赛不是初赛策略的简单延续，核心任务从基础维持/简单 reference 跟踪变成了带电源响应、时延和硬约束的位形转换控制。

当前可复用的初赛经验：

| shot 前缀 | 位形语义 |
| --- | --- |
| `15892_*` | limiter |
| `13844_*` | divertor |
| `13906_500` | XPT |

据此，复赛任务的合理训练映射应为：

| 子任务 | 起点位形 | 推荐起点 shot | 目标 |
| --- | --- | --- | --- |
| `F1` | divertor | `13844_500`, `13844_600` | limiter target |
| `F2a` | divertor | `13844_500`, `13844_600` | XPT target |
| `F2b` | limiter | `15892_400`, `15892_500` | XPT target |

`13906_500` 更适合作为 XPT 目标附近稳定控制或 XPT hold 预训练场景，不应和 `13844/15892` 随意混成同一种 start-shot 分布。

关键原则：目标位形和 shot 配置不能任意匹配。不同 shot 对应不同初始平衡、位形类别和可达性，错误组合可能不是“难训练”，而是物理上不合理或不可达。

## 2. 硬约束与 reward 分工

复赛评分强调硬约束，但并不是所有硬约束都应该放进 reward。

适合代码层面直接保证的约束：

- 动作上下界：直接 clip。
- 7D 上下对称控制：通过 action wrapper 保证。
- 最终输出 12D 物理电压：由 inference 代码保证。
- 推理接口、双服务、模型路径：由 submission 模板保证。

适合安全层 + reward 共同处理的约束：

- `I_PF` 线圈电流限制。一次超限会导致该步及后续清零，所以应有接近阈值的软惩罚，并在推理侧考虑动作降幅或限幅安全层。
- `Ip` 偏差 50 kA 熔断。reward 应与该阈值对齐，同时可考虑 emergency 逻辑避免持续偏离。

`Ip` 边界惩罚不应使用无限平方项。复赛评分是 50 kA 熔断/系数清零语义，而不是偏差越大扣分无限放大；stage0 日志已经显示无限平方会在严重失控窗口压制所有 shaping 信号。当前建议使用 Huber + cap：40-50 kA 附近保持二次边界感，超过该区间后线性增长，并用 `ip_error_boundary_penalty_cap` 限制最大单步惩罚。

必须依靠策略学习的约束：

- `F1`: 目标拓扑为 limiter，最终需要 `lX -> 0`。
- `F2`: 目标拓扑为 XPT/divertor，最终需要 `lX -> 1` 且 `nX -> 4`。
- F2 的 X 点位置、打击点位置和 X 点磁通一致性。

reward 应更像评分代理，而不是物理量大杂烩。早期 reward 优先覆盖 `Ip`、LCFS、基础拓扑和线圈风险；F2 的 `psiX`、strike、等磁通残差等物理项应按课程逐步增强。

注意点/隐患：复赛本地评分脚本没有单独的 `R`、`Z` 或初赛式 `pos` 得分项。F1 显式计分项是 `Ip` 和绝对坐标 LCFS；F2 在此基础上增加 X 点、strike 和 X 点磁通偏差。`R/Z` 漂移会通过 LCFS 绝对坐标误差、X 点/strike 几何误差等间接影响得分，但不是独立评分项。因此 `R/Z` reward 应被视为训练 shaping：在 stage0 平衡维持阶段保留低到中等权重是合理的，有助于模型学习径向/垂直稳定；进入评分对齐阶段后，需要重新评估 `R/Z` 项是否与 LCFS 绝对误差冗余，避免它挤占 `Ip`、LCFS、拓扑和硬约束相关项的优化权重。

## 3. 电压控制、时延与历史观测

复赛策略输出的是电压指令，动作进入 HFM 前会经过：

```text
U_set -> 传输时延 -> 变化率限幅 -> PSM 仿射 -> HFM
```

这意味着当前 action 的效果会滞后，且电源模型内部有历史状态。仅使用单步 observation 会让问题更接近部分可观测控制，尤其对变电流/变位置任务不利。

后续 observation 应加入历史信息，但从第一个正式 stage 就固定输入结构，避免中途改变输入维度导致模型重学。

建议历史特征：

- 过去 `K` 步 7D action，按动作上限归一化。
- `delta Ip / 50_000`。
- `delta R / 0.03`, `delta Z / 0.03`。
- `delta I_PF / COIL_LIMITS_A`。
- 可选：过去若干步主要误差项，不直接拼 reward 标量。

不建议直接拼大量原始历史 observation，否则输入维度增长过快，且量纲混乱。

## 4. 分阶段训练原则

官方建议避免一开始就把“稳态维持”和“长距离位形转换”混在一起训练。结合初赛经验，我们进一步固化为以下原则：

- 固定最终 observation 结构，从 stage 0 开始就包含后续会用到的字段。
- 固定最终 action 语义，从 stage 0 开始使用归一化 `[-1, 1]^7` 对称动作；进入 HFM 前再缩放到 7D 物理电压并映射为 12D。
- 电源模型从一开始启用，不先绕过电源再切换。
- 阶段之间只连续改变目标难度、horizon、扰动范围和 reward 权重。
- 不在中后期突然新增 XPT 输入、历史输入或改变归一化方式。
- 不在 stage 0 一开始就加入大范围 `signeo/bp/q0` 扰动。

推荐课程：

### Stage 0: 基础动态控制

- 固定 shot，优先使用任务对应的 start-shot。
- 短 horizon。
- 训练 `Ip/R` 小范围动态控制。
- `Z`、LCFS、XPT 拓扑项低权重或仅作观测。
- 前半期不做 reset 扰动，后半期只加入微量扰动。

建议微扰起点：

| 参数 | Stage 0 后半期建议 |
| --- | --- |
| `signeo` | `±2%` 到 `±5%` |
| `bp` | 很小绝对扰动，如 `±0.005` |
| `q0` | `±0.03` 到 `±0.05` |

官方文档中的 `signeo ±50%`、`bp/q0 ±10%` 应作为后期泛化增强，而不是 stage 0 默认设置。

Stage 0b 的语义是 `hold_initial + perturb`：reset 后仍维持当前初始平衡，但初始参数从 `signeo/bp/q0` 候选中随机扰动一个。这样能扩大初始平衡分布，同时避免三个参数同时变化把等离子体初态推到不合理或难求解区域。当前建议起点是 `signeo` 缩放 `0.98-1.02`，`bp` 绝对扰动 `±0.005`，`q0` 绝对扰动 `±0.03`。如果后续要验证联合扰动，应单独建立配置并做 smoke test。

### Stage 1: 近距离位形过渡

- 保持输入结构不变。
- 逐步加入 LCFS 目标。
- 目标从当前 shot 附近的小偏移开始，避免直接长距离拉到最终目标。
- 线圈风险和动作平滑开始进入训练约束。

### Stage 2: 完整子任务过渡

- `F1`: `13844_* -> limiter target`，完整 300 步。
- `F2a`: `13844_* -> XPT target`，完整 500 步。
- `F2b`: `15892_* -> XPT target`，完整 500 步。
- F2 的 `lX/nX/X点/strike/psiX` 权重逐步增强。

### Stage 3: 混合与泛化

- `policy1` 混合 `13844_500/13844_600`。
- `policy2` 混合 `F2a` 和 `F2b` 起点，即 `13844_*` 与 `15892_*`。
- 扩大 reset 扰动，但应逐步增大到官方建议范围。
- 可冻结或谨慎更新观测归一化统计，避免后期分布漂移破坏已学策略。

### Stage 4: 鲁棒性与安全

- 加强延迟扰动、噪声、线圈安全边界检查。
- 加入或调强推理侧安全层。
- 用本地评分脚本和 HFM 联调结果诊断 F1/F2a/F2b 分项丢分。

## 5. 输入归一化原则

初赛经验表明，观测归一化对 PPO 很重要。复赛建议采用“固定物理归一化 + 可选 VecNormalize”的组合。

第一层：固定物理归一化。

- `Ip` 用 `5e5` 或 `1e6` 缩放。
- `Ip - reference_Ip` 用 `50_000` 缩放，对齐熔断阈值。
- `R/Z` 误差用 `0.03 m` 缩放，对齐 3 cm 评分尺度。
- LCFS reward/评分代理必须使用装置绝对坐标 RMS：直接计算 `(lcfs_points - reference_lcfs_points)`，不做中心平移对齐；建议把绝对坐标和绝对误差 `(lcfs_points - reference_lcfs_points) / 0.03` 都放入特征。
- centered shape 只能作为可选辅助特征，不能替代绝对坐标 LCFS 误差，也不能作为复赛 LCFS reward 的代理。
- `I_PF` 用各自 `COIL_LIMITS_A` 缩放，比统一常数更贴近复赛硬约束。
- X 点位置误差用 `0.03 m` 缩放。
- strike 误差用 `0.10 m` 缩放。
- `FX - FB` 用 `0.003` 或 `0.005` 缩放，对齐 XPT 评分阈值。
- `lX/nX/valid mask` 保留为有限范围标量，不做 running mean/std 语义变换。

第二层：历史特征按同一物理尺度归一化。

第三层：训练时可使用 `VecNormalize` 稳定 PPO，但不能让它独自承担全部归一化。

VecNormalize 使用约束：

- `policy1` 和 `policy2` 独立保存 stats。
- stage 之间延续 stats，不随意重置。
- 后期 fine-tune 可考虑冻结 obs stats。
- submission 必须加载相同 metadata 和 stats。

## 6. 后续实现落点

当前第一版 `training/features.py` 主要保证稳定 flatten 和 metadata，同步解决训练/推理输入顺序一致问题。它还不是最终高分版输入。

后续建议实现：

- `PhysicalFeatureBuilder`: 评分阈值对齐的物理归一化。
- `HistoryObservationWrapper`: 固定长度历史 action/delta 特征。
- `TaskStageConfig`: 显式描述 `subtask`, `stage`, `shot_pool`, `target_type`, `reset_perturbation`, `reward_weights`。
- `ShotTargetRegistry`: 固化 `15892=limiter`, `13844=divertor`, `13906=XPT`，避免任意 shot-target 配对。
- `SafetyActionWrapper`: 训练和推理一致的动作限幅/平滑/线圈风险保护。

这些改动应在训练前先通过离线测试验证输入维度、metadata、归一化尺度和推理侧一致性。
